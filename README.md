# シフト給料アプリ

シフトを登録するだけで、給料の見込みを自動計算してくれるWebアプリです。ブラウザで開くだけで動き、データはその端末のブラウザ内（localStorage）に保存されます。

## 概要

- 複数のバイト先を登録でき、バイト先ごとに時給や深夜割増率を設定できます。
- シフトを入れるたびに給料が自動で計算され、月ごとの合計やバイト先ごとの小計が一目で分かります。
- 深夜をまたぐシフト（例：22:00〜翌2:00）にも対応しています。
- `index.html` の1ファイルだけで完結し、外部ライブラリは使っていません。

## 機能

### バイト先の設定
- 名前・時給・深夜割増率（初期値25%）・色を登録できます。
- 追加・編集・削除ができます。

### シフト登録
- 日付・バイト先・開始時刻・終了時刻・休憩時間（分）・メモを登録できます。
- 終了時刻が開始時刻より早い場合は、翌日まで働いたものとして計算します。
- 追加・編集・削除ができます。

### 給与計算
- 実働時間 ＝ 終了 − 開始 − 休憩 で計算します。
- 22:00〜翌5:00 は深夜帯として、時給 ×（1 ＋ 割増率）で計算します。
- 休憩時間は、深夜帯以外の時間から先に差し引きます。
- 金額は円未満を切り捨てます。

### 月表示
- その月のシフト一覧（日付順）、合計給料見込み、合計労働時間、バイト先ごとの小計を表示します。
- 前月・翌月への切り替えができます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「バイト先の設定」から、バイト先の名前と時給を登録します。
3. 「シフトを追加」からシフトを登録すると、給料が自動計算されます。
4. 上部の ◀ ▶ で月を切り替えて、月ごとの合計を確認できます。

## データについて

データはブラウザの localStorage に保存されます。別の端末や別のブラウザとは共有されません。ブラウザのデータを消去すると登録内容も消えるのでご注意ください。

## 動作環境

モダンブラウザ（スマートフォン・PC両対応）。インターネット接続は不要です。
